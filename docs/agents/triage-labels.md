# Triage labels

Use these strings in a local ticket's `Status` field when recording triage state.

| Role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Implementation completion and wayfinding lifecycle conventions are defined in `issue-tracker.md`.
