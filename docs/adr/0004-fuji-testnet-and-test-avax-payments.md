# ใช้ Avalanche Fuji และ test AVAX สำหรับรุ่นงานแข่ง

รุ่นงานแข่ง deploy smart contract และทำธุรกรรมซื้อขายโทเคนสิทธิ์บน Avalanche Fuji testnet โดยใช้ test AVAX เป็นสกุลเงินซื้อขายตามที่ผู้ใช้ยืนยัน แทนการใช้เงินจริงหรือเพิ่มโทเคนชำระเงินอีกชนิดในรุ่นนี้

## Consequences

- ราคาและการแบ่งรายได้ 90% ให้ผู้ขาย / 10% ให้แพลตฟอร์มคำนวณในหน่วย test AVAX
- แพลตฟอร์มมี test AVAX สำหรับออก gas ของการซื้อ ตาม ADR-0003
- การทดลองนี้ไม่ใช่การรับชำระเงินจริง และการเปิด mainnet ต้องมีการตัดสินใจแยกต่างหาก
- การเลือกเครือข่ายนี้ใช้กับ smart contract; frontend, backend และไฟล์ ZIP ที่เข้ารหัสยังต้องมี hosting และ IPFS แยกตามหน้าที่
