# ผู้สร้างเผยแพร่ผลงานได้โดยไม่รออนุมัติ

เมื่อผู้สร้างลงผลงานและเลือกเผยแพร่ รายการสามารถแสดงต่อผู้ชมได้ทันทีโดยไม่ต้องผ่านการอนุมัติของแอดมิน เพื่อให้ผู้สร้างดำเนิน flow การขายได้ด้วยตัวเอง การเผยแพร่ต้องสอดคล้องกับสถานะข้อมูลและไฟล์จริง เช่น ไม่แสดงว่าซื้อและรับ source ได้แล้วหากไฟล์ยังจัดเก็บไม่สำเร็จ

## Consequences

- ไม่มีคิวตรวจอนุมัติก่อนเผยแพร่
- การตรวจความครบถ้วนของข้อมูลและความสำเร็จของการจัดเก็บไฟล์เป็นการตรวจทางเทคนิค ไม่ใช่การอนุมัติโดยแอดมิน
- กลไกรายงานผลงานและการระงับภายหลังยังไม่ได้กำหนด
