# แยกสิทธิ์ขายสิทธิ์เดิมต่อออกจากการขายผลงานต่อยอด

ผู้สร้างแต่ละผลงานกำหนดได้ว่าอนุญาตให้ผู้ซื้อขายและโอนสิทธิ์เดิมต่อหรือไม่ โดยแยกจากเงื่อนไขอนุญาตขายผลงานต่อยอด และต้องแสดงเงื่อนไขก่อนซื้อ การแยกนี้ทำให้การซื้อเพื่อโอนต่อไม่ถูกตีความว่าอนุญาตให้ดัดแปลงหรือขายสำเนาของ source โดยอัตโนมัติ

## Consequences

- การโอน token ต้องสอดคล้องกับเงื่อนไขการโอนสิทธิ์ของผลงานนั้น รูปแบบมาตรฐาน token ยังไม่ได้เลือก
- ผู้ขายสิทธิ์เดิมต่อสิ้นสุดสิทธิ์ที่โอนตามเงื่อนไข แต่ระบบไม่สามารถลบสำเนา source ที่ดาวน์โหลดไปแล้ว
- U-Bot และการเผยแพร่ผลงานใหม่ต้องตรวจสิทธิ์ต่อยอดแยกจากสิทธิ์ขายต่อ
- เมื่อต้นทางอนุญาตให้ต่อยอดเพื่อขาย ผลงานต่อยอดถือเป็นสินค้าใหม่และขายพร้อม source ได้ โดยไม่แยกตัวเลือกอนุญาตส่งต่อ source เพิ่มอีกชั้น
- การขายผลงานต่อยอดไม่มีส่วนแบ่งรายได้ให้ผู้สร้างต้นทาง; ค่าธรรมเนียมแพลตฟอร์มเป็นไปตาม ADR-0003
