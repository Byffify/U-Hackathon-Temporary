# บัญชีผู้ใช้ผูกกับ wallet และใช้ได้ทั้งซื้อและขาย

U-topia ใช้การเชื่อม wallet เป็นช่องทางหลักในการเข้าสู่ระบบ โดยบัญชีเดียวเป็นได้ทั้งผู้ซื้อและผู้สร้าง พร้อมชื่อ รูป และประวัติในโปรไฟล์ การเลือกนี้ทำให้การระบุบัญชีสอดคล้องกับสิทธิ์ซื้อบน Avalanche โดยไม่แยกบัญชีผู้ซื้อกับผู้ขาย

## Consequences

- การยืนยันตัวตนฝั่ง backend ต้องพิสูจน์การควบคุม wallet ไม่ใช่อาศัย address ที่ frontend ส่งมาเพียงอย่างเดียว
- โปรไฟล์ผู้สร้างและผลงานผูกกับบัญชีผู้ใช้เดียวกัน
- การเปลี่ยน wallet หรือการกู้บัญชียังไม่ได้กำหนด และจะไม่ถือว่า wallet คนละใบเป็นบัญชีเดียวกันโดยอัตโนมัติ
