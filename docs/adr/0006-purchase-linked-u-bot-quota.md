# จำกัดโควตา U-Bot เฉพาะงานรวมหลายโปรเจกต์

รุ่นแรกให้แพลตฟอร์มรับต้นทุน API ของ U-Bot โดยจำกัดโควตาและหักตามปริมาณใช้งาน และยังไม่เพิ่มระบบขายเครดิต ตามข้อสรุปล่าสุด โควตานี้ใช้เฉพาะผู้ที่เรียก U-Bot เพื่อรวมหลายโปรเจกต์ ไม่แจกเครดิตอัตโนมัติเมื่อซื้อโปรเจกต์ ซึ่งแทนข้อสรุปเดิมเรื่องเครดิตต่อการซื้อ

## Consequences

- การซื้อทั้งจากผู้สร้างและการซื้อสิทธิ์มือสองไม่ทำให้ได้รับเครดิตโดยอัตโนมัติ
- เครดิต U-Bot เป็นโควตาการใช้ AI แยกจากโทเคนสิทธิ์เข้าถึง source
- โควตาเป็นก้อนต่อบัญชีสำหรับช่วงทดลอง ใช้ร่วมกันทุกงานรวมโปรเจกต์ของบัญชีนั้น ไม่มีรีเซ็ตรายวันและไม่มีระบบเติมเครดิต
- จำนวนโควตา วิธีเปิดใช้โควตาสำหรับงานรวม สูตรหักเครดิต วันสิ้นสุดช่วงทดลอง และการจัดการงานที่ล้มเหลวต้องกำหนดก่อนนำไปใช้
- พักการเลือกผู้ให้บริการโมเดลไว้ตามที่ผู้ใช้ขอ โดยยังไม่มีเอกสารของบริการที่ผู้ใช้เรียกว่า Tokenomit ให้ตรวจยืนยัน; หากหมายถึง Tokenomist ที่ตรวจเอกสารแล้ว บริการนั้นเป็น API ข้อมูล tokenomics แยกจากโมเดลเขียนโค้ด
- งานปรับปรุงโปรเจกต์เดี่ยวอยู่นอกขอบเขต U-Bot ตาม ADR-0005 ฉบับแก้ไข
- ก่อนเริ่มสร้างโค้ด ระบบต้องแสดงโควตาที่คาดว่าจะใช้และแจ้งหากโควตาไม่พอ ผู้ใช้ปรับเพิ่ม ลด หรือเปลี่ยนฟีเจอร์ในแผนได้ แล้วตรวจโควตาอีกครั้งก่อนยืนยัน
- เมื่อโควตาไม่พอจะยังเริ่มงานสร้างโค้ดไม่ได้ โดยไม่มีการเรียกเก็บเงินเพิ่มหรือระบบเติมเครดิตในรุ่นนี้
