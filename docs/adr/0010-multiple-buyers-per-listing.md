# หนึ่งรายการขายสิทธิ์ให้ผู้ซื้อหลายคนได้

โปรเจกต์หนึ่งรายการขายให้ผู้ซื้อหลายคนได้ โดยแต่ละคนได้รับ token สิทธิ์ของตัวเอง การซื้อจึงไม่ใช่การขายขาดตัวผลงานให้ผู้ซื้อคนเดียว และไม่ทำให้รายการนั้นขายหมดเพราะมีคนซื้อแล้ว

## Consequences

- การขายสิทธิ์เดิมต่อเป็นการโอนสิทธิ์ของผู้ซื้อรายนั้น ไม่กระทบสิทธิ์ของผู้ซื้อรายอื่นหรือความสามารถของผู้สร้างในการขายรายการเดิม
- Contract ต้องแยกผู้สร้างรายการออกจากผู้ถือสิทธิ์ที่ซื้อ และรองรับผู้มีสิทธิ์หลายคนในรายการเดียวกัน
- มาตรฐาน token ยังไม่ได้กำหนดจากการตัดสินใจนี้
