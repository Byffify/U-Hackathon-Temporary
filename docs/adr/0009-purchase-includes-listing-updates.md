# ซื้อครั้งเดียวได้รับอัปเดตฟรีจากรายการเดิม

ผู้ซื้อโปรเจกต์ได้รับอัปเดตที่ผู้สร้างเผยแพร่ภายใต้รายการเดิมโดยไม่ต้องซื้อซ้ำ ส่วนผลงานที่เผยแพร่เป็นรายการขายใหม่ต้องซื้อแยก การตัดสินใจนี้ผูกสิทธิ์รับอัปเดตกับรายการที่ซื้อ แทนการขายสิทธิ์แยกทุกเวอร์ชัน

## Consequences

- รายการหนึ่งอาจมี source ZIP หลายเวอร์ชัน และผู้มีสิทธิ์เข้าถึงอัปเดตในรายการนั้นได้
- การตรวจสิทธิ์ดาวน์โหลดต้องรองรับการซื้อก่อนวันที่เผยแพร่เวอร์ชันอัปเดต
- ความสัมพันธ์ระหว่างการโอนสิทธิ์กับสิทธิ์รับอัปเดต และการเปลี่ยนเงื่อนไขสิทธิ์ในเวอร์ชันใหม่ ต้องระบุให้ชัดก่อนออกแบบ contract และการส่งมอบ
