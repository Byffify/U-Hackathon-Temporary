# ใช้ ERC-721 สิทธิ์รายผู้ซื้อและยอดฝากสำหรับ sponsored purchase บน Fuji

สำหรับสัญญารุ่นงานแข่ง U-topia ใช้ ERC-721 หนึ่ง token ต่อสิทธิ์ที่ซื้อของแต่ละผู้ซื้อ ผูก token กับ listing และ snapshot ของ hash เงื่อนไขสิทธิ์ที่เสนอ ณ เวลาซื้อ ผู้สร้างแก้ราคาและเงื่อนไขสำหรับการซื้อครั้งใหม่ได้ แต่ไม่แก้ snapshot ของ token ที่ออกแล้ว สิทธิ์รับ release ใหม่ใน listing เดิมติดตามเจ้าของ token ปัจจุบันหลังการขายต่อ

การซื้อใช้ test AVAX ที่ผู้ซื้อฝากไว้ก่อน ผู้ซื้อเซ็น EIP-712 authorization ซึ่งผูก buyer, listing หรือ resale token, ราคา, hash เงื่อนไข, nonce, วันหมดอายุ, contract และ chain ID บัญชี sponsor ที่กำหนดไว้ส่งธุรกรรมซื้อและจ่าย gas สัญญาหักยอดฝากของผู้ซื้อ แบ่งเครดิต 90% ให้ผู้ขายและ 10% ให้แพลตฟอร์ม แล้วออกหรือโอน token ในธุรกรรมเดียว เครดิตถอนแยกเพื่อไม่ให้ address ผู้รับที่รับ AVAX ไม่ได้ขัดขวาง settlement

การฝาก test AVAX ยังเป็นธุรกรรมที่ผู้ซื้อต้องจ่าย gas เอง วิธีนี้จึงทำให้ **ธุรกรรมซื้อ** ไม่มี gas debit จากผู้ซื้อ แต่ยังไม่ครอบคลุม onboarding ที่ไม่มี gas ทุกขั้นตอน หากต้องการประสบการณ์นั้น ต้องออกแบบกลไก funding หรือ account abstraction เพิ่ม โดยยังรักษาหลักว่าราคาสินค้าจากผู้ซื้อและ gas จากแพลตฟอร์มเป็นคนละต้นทุน

การโอน token ทั่วไปถูกปิด; การขายสิทธิ์เดิมต่อทำได้ผ่าน offer และ settlement ใน marketplace เมื่อ snapshot ของสิทธิ์นั้นอนุญาต ส่วนสิทธิ์ขายผลงานต่อยอดบันทึกแยกและ backend ต้องตรวจ provenance ก่อนเผยแพร่รายการใหม่ ไม่มี royalty ต้นทาง

Backend ยังคงรับผิดชอบยืนยัน wallet, ตรวจ chain และ contract ที่เชื่อถือได้, ตรวจเจ้าของ token ปัจจุบันก่อนถอดรหัส ZIP, เก็บ release และกุญแจนอกเชนตาม ADR-0001
