# Backend ดูแลกุญแจถอดรหัสโปรเจกต์ต้นฉบับ

สำหรับเวอร์ชันงานแข่ง ผู้สร้างส่งโปรเจกต์เป็น ZIP ซึ่งต้องเข้ารหัสก่อนเก็บบน IPFS ปกติ และ backend ของ U-topia ดูแลกุญแจนอกเชน โดยยืนยันเจ้าของ wallet และตรวจ token สิทธิ์ของโปรเจกต์บน Avalanche ก่อนอนุญาตถอดรหัส การตัดสินใจนี้ช่วยให้ทำ flow ซื้อและรับ source ได้ภายในกำหนดส่ง 16 ตุลาคม 2026 เวลา 12:00 น. Asia/Bangkok โดยผู้ใช้ยอมรับการเชื่อถือ U-topia ในการดูแลกุญแจ แทนการเพิ่มระบบจัดการกุญแจแบบกระจายศูนย์ในรุ่นนี้

## Consequences

- เก็บเฉพาะไฟล์ที่เข้ารหัสบน IPFS; กุญแจถอดรหัสต้องไม่เปิดเผยบนเชนหรือใน metadata สาธารณะ
- Backend เป็นจุดที่ต้องรักษาความพร้อมใช้งานและปกป้องกุญแจ รวมถึงสำรองและกู้คืนอย่างปลอดภัย
- การได้รับ source หลังถอดรหัสทำให้ผู้ซื้อสามารถเก็บสำเนาได้ การตรวจ token ไม่สามารถเรียกคืนสำเนาที่ผู้ซื้อได้รับแล้ว
- รูปแบบ token การโอนสิทธิ์ และนโยบายเวอร์ชันไฟล์ยังไม่ได้ข้อสรุปจากผู้ใช้
